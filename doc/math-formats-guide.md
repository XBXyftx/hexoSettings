## 📐 支持的数学公式格式

本博客使用 **MathJax 3.2.2** 作为数学公式渲染引擎，支持以下输入格式：

| 格式类型 | 语法 | 示例 | 渲染效果 |
| -------- | ---- | ---- | -------- |
| 行内公式（TeX 风格） | `$...$` | `$E=mc^2$` | $E=mc^2$ |
| 行内公式（LaTeX 风格） | `\(...\)` | `\(a^2 + b^2 = c^2\)` | \(a^2 + b^2 = c^2\) |
| 块级公式（TeX 风格） | `$$...$$` | `$$\int_{a}^{b} f(x)dx$$` | 独立居中显示 |
| 块级公式（LaTeX 风格） | `\[...\]` | `\[\sum_{i=1}^{n} x_i\]` | 独立居中显示 |
| MathML | `<math>...</math>` | - | 标准数学标记语言 |
| AsciiMath | 特定语法 | `` `sqrt(x^2+y^2)` `` | 简化输入语法 |

## ⚠️ 重要注意事项

### 1. 在文章 Front-matter 中启用 MathJax

**必须**在需要使用数学公式的文章头部添加 `mathjax: true`：

```yaml
---
title: 你的文章标题
date: 2026-01-01 00:00:00
mathjax: true   # ← 必须添加这一行！
---

现在可以使用 $E=mc^2$ 这样的行内公式了。
```

> 💡 说明：`_config.butterfly.yml` 中设置了 `per_page: false`，即按需加载模式。这可以优化页面加载速度，只在需要渲染公式的页面加载 MathJax 库。

### 2. 🚨 Markdown 表格中的数学公式冲突问题

#### 问题描述

在 Markdown 表格中使用数学公式时，公式中的 `|`（竖线/管道符）会与 Markdown 表格的列分隔符 `|` **产生渲染冲突**。

**❌ 错误示例**（会导致表格渲染失败）：

```markdown
| 公式 | 说明 |
|------|------|
| $P(A \| B) = \frac{P(B \| A)P(A)}{P(B)}$ | 贝叶斯定理 |
| $\{x \| x > 0\}$ | 集合定义 |
```

#### 解决方案

使用 **HTML 实体** `&#124;` 或 `&vert;` 替代数学公式中的 `|` 符号。

**✅ 正确示例**：

```markdown
| 公式 | 说明 |
|------|------|
| $P(A &#124; B) = \frac{P(B &#124; A)P(A)}{P(B)}$ | 贝叶斯定理 |
| $\{x &#124; x > 0\}$ | 集合定义 |
| $\vert x \vert$ | 绝对值 |
```

**常用替代对照表**：

| 原符号 | HTML 实体 | 说明 |
| ------ | --------- | ---- |
| `\|` | `&#124;` 或 `&vert;` | 竖线（条件概率、集合） |
| `\vert` | `\vert` | 在公式中可直接使用 `\vert` |
| `\Vert` | `\Vert` | 双竖线（范数） |

#### 最佳实践

1. **优先使用 LaTeX 命令**：在公式内部使用 `\vert` 或 `\mid` 代替 `|`

   ```markdown
   | 公式 | 说明 |
   |------|------|
   | $P(A \mid B)$ | 条件概率（使用 \mid） |
   | $\{x \vert x > 0\}$ | 集合定义（使用 \vert） |
   | $\Vert x \Vert_2$ | L2 范数（使用 \Vert） |
   ```

2. **如果必须在表格中使用 `|`**：使用 HTML 实体 `&#124;`

   ```markdown
   | 公式 | 说明 |
   |------|------|
   | $P(A &#124; B)$ | 贝叶斯公式 |
   ```

3. **复杂公式建议放在表格外**：对于包含大量竖线的复杂公式，建议单独成行显示，不放入表格中。

### 3. 公式转义问题

在 Markdown 中，某些特殊字符需要转义：

| 字符 | 问题 | 解决方案 |
| ------ | ---- | -------- |
| `_`（下划线） | 会被解析为斜体 | 在公式内使用不受影响，公式外需转义 `\_` |
| `*`（星号） | 会被解析为粗体/斜体 | 公式内正常使用 |
| `\`（反斜杠） | Markdown 转义符 | 公式内正常使用 |

**示例**：

```markdown
<!-- 行内公式中的下划线不会变成斜体 -->
$a_{ij}$ 表示矩阵元素

<!-- 公式外的下划线需要转义 -->
变量名 a\_ij 不包含下标
```

### 4. 公式编号

当前配置 `tags: none` 表示默认不自动编号。如需编号：

```markdown
$$E=mc^2 \tag{1}$$
```

或使用 AMS 环境：

```markdown
$$\begin{equation}
E=mc^2
\end{equation}$$
```

### 5. 常见公式示例

#### 基础数学

```markdown
行内公式：$a^2 + b^2 = c^2$

块级公式：
$$\frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
```

#### 矩阵

```markdown
$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$
```

#### 多行对齐（使用 align 环境）

```markdown
$$
\begin{align}
f(x) &= x^2 + 2x + 1 \\
     &= (x+1)^2
\end{align}
$$
```

#### 条件概率（注意在表格中使用实体）

```markdown
$$P(A &#124; B) = \frac{P(A \cap B)}{P(B)}$$
```
