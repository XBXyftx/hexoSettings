# 07-known-issues — 已知问题与技术债务

本目录记录博客项目中已知的问题、待修复项和技术债务。

## 已知问题清单

### BUG-001 — 懒加载系统冗余

| 项 | 值 |
|---|---|
| **状态** | 待优化 |
| **严重程度** | 中 |
| **描述** | 项目中同时存在三套懒加载逻辑：主题内置懒加载、vanilla-lazyload 库、自定义 lazy-loading 系列脚本。逻辑有重叠，可能导致冲突或重复加载 |
| **影响** | 页面加载性能，偶尔的图片加载异常 |
| **相关文件** | `source/js/lazy-loading*.js`, `themes/butterfly/source/js/lazy-loading-optimized.js`, `vanilla-lazyload` npm 包 |
| **临时方案** | 当前通过禁用主题懒加载（`_config.butterfly.yml` 中 `lazyload.enable: false`）使用自定义方案 |
| **建议修复** | 统一为一套懒加载方案，移除冗余脚本和依赖 |

### BUG-002 — 主题升级困难

| 项 | 值 |
|---|---|
| **状态** | 长期技术债务 |
| **严重程度** | 高 |
| **描述** | Butterfly 主题 8 个核心模板文件被直接修改，大量自定义 CSS/JS 硬编码在主题中。升级主题版本需要手动合并所有修改，成本高且容易遗漏 |
| **影响** | 无法及时跟进主题安全更新和新功能 |
| **相关文件** | `themes/butterfly/layout/` 下的 8 个修改文件 |
| **临时方案** | 当前保持现有版本（v5.3.2），不主动升级 |
| **建议修复** | 将主题修改提取为独立插件或 Hexo 脚本，减少对主题文件的直接修改 |

### BUG-003 — MathJax 体积过大（已修复）

| 项 | 值 |
|---|---|
| **状态** | ✅ 已修复（2026-05-04 迁移至 KaTeX，已验证） |
| **严重程度** | 中 |
| **描述** | 本地引入了完整的 MathJax 3.2.2 库（1.1MB），但只有少数文章使用数学公式。影响首屏加载速度 |
| **影响** | 已消除 — KaTeX 0.16.19 仅 303KB，体积减少 74% |
| **相关文件** | `source/js/katex/`（KaTeX 当前方案）、`source/js/MathJax-3.2.2/`（已删除） |
| **修复方案** | 迁移至 KaTeX 客户端渲染（katex.min.js 276KB + katex.min.css 23KB + auto-render 3.5KB）。`scripts/math-protect.js` 防 kramed 破坏公式语法 |
| **关联文档** | [../04-operations/2026-05-04-katex-migration/README.md](../04-operations/2026-05-04-katex-migration/README.md) |

### BUG-004 — CDN 来源分散

| 项 | 值 |
|---|---|
| **状态** | 待优化 |
| **严重程度** | 低 |
| **描述** | 第三方库 CDN 来源分散在多个服务商（cloudflare、elemecdn、baomitu、tianli0、dusays），部分国内 CDN 可能不稳定 |
| **影响** | 偶尔的资源加载失败或慢速加载 |
| **相关文件** | `_config.butterfly.yml` 中的 `CDN.option` 配置 |
| **临时方案** | 当前多 CDN 互为备份 |
| **建议修复** | 统一为 1-2 个可靠 CDN 源，优先使用 jsdelivr 或本地托管 |

### BUG-005 — 隐私文章系统安全性不足

| 项 | 值 |
|---|---|
| **状态** | 已知限制 |
| **严重程度** | 中 |
| **描述** | 隐私文章仅通过前端 JavaScript 密码验证保护，文章 Markdown 文件和生成的 HTML 仍可通过直接访问 URL 或查看源码获取 |
| **影响** | 敏感内容不应仅依赖此系统保护 |
| **相关文件** | `source/coffer/`, `source/js/coffer.js` |
| **临时方案** | 仅用于非高度敏感内容的隔离展示 |
| **建议修复** | 增加服务端验证，或将隐私内容放在独立受保护的分支/目录 |
