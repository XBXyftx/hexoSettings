## 已知问题清单

### BUG-001 — 文章懒加载的外部尺寸边界

| 项 | 值 |
|---|---|
| **状态** | 已完成本地治理；本地图片比例拉伸回归已在 2026-07-12 修复，仍保留外部媒体的不可自动恢复边界 |
| **严重程度** | 低（目录跳转已具备运行时校正；外部图片本身仍可能引起普通阅读过程的布局变化） |
| **描述** | 原有 `lazy-loading.css`/`lazy-loading-stable.css` 曾让全篇待加载图片同时运行持续动画。2026-07-11 已改为文章页原生 `loading="lazy"` + 仅近视口轻量占位，并以可取消的 TOC 重锚定修复晚到媒体造成的目录偏移。随后发现停止旧样式加载时遗失了文章图片 `height:auto`，会使构建期注入尺寸属性的图片在窄栏被纵向拉伸；2026-07-12 已在当前文章样式入口恢复 `max-width:100%` + `height:auto`，并使最小占位高度只作用于无尺寸图片。生成态有 1,596 张正文图，1,494 张具备完整尺寸；剩余 97 张外部图和 5 个 data URI 无法由本地构建安全推断比例。 |
| **影响** | 超慢外部图在正常阅读中仍可能改变周边排版；目录点击会在有限窗口内校正，但不无限等待资源。 |
| **相关文件** | `themes/butterfly/source/js/lazy-loading-optimized.js`、`themes/butterfly/source/js/main.js`、`themes/butterfly/source/css/lazy-loading-optimized.css`、`scripts/image-dimensions.js` |
| **验证** | `OpenSourceSummer2025` 在 1440×900 与 375×812、每张本地图 400ms 延迟、额外注入 240px 布局变化时，目录误差为 `0.125px / 0.297px`；两端所有已加载带尺寸正文图比例错误均为 0。 |
| **后续** | 如获得可信原图备份或作者给出的尺寸，优先补内容源；禁止自动网络抓取或猜测性写入比例。 |

### BUG-002 — 主题升级困难

| 项 | 值 |
|---|---|
| **状态** | 长期技术债务 |
| **严重程度** | 高 |
| **描述** | Butterfly 主题 8 个核心模板文件被直接修改，大量自定义 CSS/JS 硬编码在主题中。升级主题版本需要手动合并所有修改，成本高且容易遗漏 |
| **影响** | 无法及时跟进主题安全更新和新功能 |
| **相关文件** | `themes/butterfly/layout/` 下的 8 个修改文件 |
| **临时方案** | 当前保持现有版本（v5.3.2），不主动升级 |
| **建议修复** | 将主题修改提取为独立插件或 Hexo 脚本，减少对主题文件的直接修改 |

| 项 | 值 |

| **严重程度** | 低 |
| **描述** | 第三方库 CDN 来源分散在多个服务商（cloudflare、elemecdn、baomitu、tianli0、dusays），部分国内 CDN 可能不稳定 |

| **建议修复** | 统一为 1-2 个可靠 CDN 源，优先使用 jsdelivr 或本地托管 |
