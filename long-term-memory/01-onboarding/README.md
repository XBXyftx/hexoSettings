## 交接流程

1. **第一步**：阅读本目录下的 `onboarding-prompt.md`
2. **第二步**：阅读根目录的 `../MEMORY.md` 索引
3. **第三步**：根据当前任务定位到对应子目录的引导文档
4. **第四步**：开始执行具体任务
